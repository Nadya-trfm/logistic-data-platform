# Logistic Data Platform

Прототип платформы данных для анализа и прогнозирования тарифов на грузоперевозки.

**Как это работает:**

```
сырые данные (public) → ETL → core (DWH) → mart (витрины) → ML-прогноз
```

1. **ETL** — SQL-скрипты загружают данные, проверяют качество и откладывают некорректные записи в карантин (`dq`).
2. **Витрина** — рыночный коридор ставок по маршрутам (медиана, квартили, число рейсов и перевозчиков).
3. **ML** — модель CatBoost прогнозирует тариф. Ridge используется как базовая модель для сравнения.

## Технологии

PostgreSQL 17, Python 3.11, Docker, pandas, scikit-learn, CatBoost, pytest.

## Быстрый старт

Нужны Docker и Python 3.11+.

**1. Запустите базу данных.** При первом запуске она сама создаст схему и сгенерирует 300 000 тестовых сделок.

```bash
docker compose up db
```

**2. Установите зависимости** (в другом терминале):

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

**3. Запустите ETL и постройте витрину:**

```bash
python -m etl.run_pipeline all
```

**4. Обучите модель и сохраните прогнозы:**

```bash
python -m ml.run_ml
```

## Команды ETL

```bash
python -m etl.run_pipeline <команда> [--start-date ГГГГ-ММ-ДД] [--end-date ГГГГ-ММ-ДД] [--as-of ГГГГ-ММ-ДД]
```

| Команда | Что делает                       |
| ------- | -------------------------------- |
| `init`  | создаёт схемы и таблицы          |
| `etl`   | загружает данные в `core`        |
| `marts` | строит витрину `mart_route_card` |
| `all`   | выполняет все три шага           |

Повторный запуск за тот же период не создаёт дубликатов.

## Тесты

База данных должна быть запущена, а ETL выполнен:

```bash
pytest
```

## Настройки (`.env`)

| Переменная                              | Описание                                   | По умолчанию    |
| --------------------------------------- | ------------------------------------------ | --------------- |
| `POSTGRES_USER` / `POSTGRES_PASSWORD`   | доступ к БД                                | `postgres`      |
| `POSTGRES_DB`                           | имя БД                                     | `deals_bigdata` |
| `POSTGRES_HOST` / `POSTGRES_PORT`       | адрес БД                                   | `localhost` / `5432` |
| `AS_OF`                                 | дата среза данных                          | `2026-10-26`    |
| `START_DATE` / `END_DATE`               | период загрузки (пусто — все данные)       | —               |
| `RANDOM_SEED`                           | зерно для обучения модели                  | `42`            |

## Структура проекта

```
sql/source/   схема и генератор тестовых данных
sql/etl/      шаги ETL
sql/*.sql     таблицы core и mart, построение витрины, примеры запросов
etl/          запуск ETL и сборка витрин
ml/           признаки, обучение, прогнозы
tests/        тесты
docker/       инициализация PostgreSQL
```

## Результаты

После запуска в базе доступны:

- `mart.mart_route_card` — рыночный коридор ставок по маршрутам;
- `mart.ml_price_predictions` — прогнозы и фактические цены;
- `mart.ml_model_metrics` — метрики моделей (R², MAPE, RMSE, MAE);
- `dq.*` — записи, не прошедшие проверки качества.

Обученная модель сохраняется в папку `artifacts/`.

## Ограничения

- Бонусные части (Airflow, Superset, ClickHouse) не реализованы.
